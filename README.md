# 3D printer profiles

Firmware, slicer settings and filament profiles, organised per printer.

```
printers/
  <printer>/
    firmware/     Marlin config + flashing notes
    slicer/       Orca machine/process profiles and G-code
    filaments/    per-material profiles and notes
    calibration.md
```

To add a printer, copy `printers/ender3-ng-corexy` and edit.
